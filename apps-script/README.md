# Apps Script 설정

`Code.gs`는 교복체크 사이트의 서버 역할을 합니다.

- 비밀번호 확인
- 시트 읽기
- 기록 저장

사이트는 이 웹앱을 통해서만 시트에 접근합니다.

## 적용 순서

**1. 코드 교체**
기존 Apps Script 프로젝트를 열고, `Code.gs` 내용을 이 폴더의 `Code.gs`로 전부 바꿉니다. 맨 위 `SHEET_ID`가 실제 시트 ID와 같은지 확인합니다.

**2. 비밀번호 설정**
왼쪽 ⚙️ **프로젝트 설정** → 맨 아래 **스크립트 속성** → **속성 추가**를 누릅니다.

- 속성: `APP_PASSWORD`
- 값: 사이트 비밀번호

비밀번호는 코드에 쓰지 말고 반드시 여기에 넣으세요. 이 폴더는 GitHub에 공개될 수 있습니다.

**3. 같은 주소로 재배포**
**배포** → **배포 관리** → 기존 웹앱 배포의 ✏️(수정)을 누르고 아래처럼 설정한 뒤 **배포**합니다.

- 버전: **새 버전**
- 실행 사용자: **나**
- 액세스 권한: **모든 사용자**

권한 승인 창이 뜨면 승인합니다. 기존 배포를 수정하면 웹앱 주소가 그대로라서 `index.html`의 `APPS_URL`을 바꿀 필요가 없습니다.

> "모든 사용자"로 두어야 사이트에서 호출할 수 있습니다. 대신 로그인 말고는 모든 요청이 비밀번호로 받은 토큰을 확인하므로, 주소를 알아도 데이터를 읽거나 쓸 수 없습니다.

**4. 예전 배포 보관 처리**
배포 관리에 다른 웹앱 배포가 남아 있으면 **보관처리**합니다. 예전 배포는 예전 코드(비밀번호 없음)로 계속 동작합니다.

**5. 시트 공유 끄기**
구글 시트 **공유** → 일반 액세스를 **제한됨**으로 바꿉니다. 지금까지는 사이트가 시트를 공개 링크로 직접 읽었기 때문에, 시트 ID만 알면 누구나 학생 명단을 볼 수 있었습니다. 이제는 Apps Script가 소유자 권한으로 읽으므로 공개할 필요가 없습니다.

**6. 사이트 반영**
위 1~5를 마친 뒤 `index.html` 변경을 `main`에 반영합니다. 순서가 바뀌면 그 사이에는 로그인이 되지 않습니다.

## 운영

- **비밀번호 변경:** `APP_PASSWORD` 값을 바꾸면 모든 기기가 로그아웃되고 새 비밀번호로 다시 로그인해야 합니다.
- **로그인 잠금:** 10분 안에 비밀번호를 10번 틀리면 10분 동안 **모든 사람의** 로그인이 막힙니다. 이미 로그인된 기기는 영향이 없습니다.
- **로그인 유지:** "이 기기에서 로그인 유지"를 체크하면 30일, 체크하지 않으면 브라우저 탭을 닫을 때까지 유지됩니다. 학교 공용 PC에서는 체크하지 마세요.

## 시트 구조

| 탭 | A | B | C | D | E |
|---|---|---|---|---|---|
| 학생 | 학년 | 반 | 번호 | 이름 | 성별 |
| 기록 | 날짜 | 학년 | 반 | 이름 | |

같은 반에 이름이 같은 학생이 있으면 기록에서 구분되지 않습니다. 이 경우 사이트에 경고가 뜹니다. 이름 뒤에 A/B 등을 붙여 구분해 주세요.
